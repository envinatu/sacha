# sacha 0.1.0

* Initial CRAN release.
* Added taxonomic accessors for names, classifications, synonyms, common names, geographic records, references, and external identifiers, with Markdown variants.
* Added functions to retrieve and save GBIF occurrences and create interactive or static maps, including cropped maps.
* Added functions to retrieve iNaturalist observations and photographs, save images, and create image compositions.
* Added configuration and report functions to combine taxonomic, geographic, and image information in Markdown species profiles.
